OM BUTIKEN

Filmhyllan låter dig bläddra bland Stockholms stadsbiblioteks filmer som i en gammal videobutik: efter genre, bibliotek, språk och åldersgräns. Ett hobbyprojekt, inspirerat av Nomad Library.

  • Inte kopplat till Stockholms stadsbibliotek. Lån och reservation sker på bibliotekets egen sida.
  • Katalogen hämtas en gång per natt. ”Inne” visar läget vid senaste hämtningen, så dubbelkolla innan du går dit.
  • Betyg, handling, trailers och åldersgränser kommer från TMDb. Matchningen är automatisk och kan ibland bli fel. Åldersgränser från andra länder än Sverige visas med landskod.

VILLKOR

  • Gratis, utan reklam och utan kommersiellt syfte. Tillhandahålls i befintligt skick, utan garantier om att uppgifterna stämmer.
  • Omslag och filmdata tillhör respektive rättighetsinnehavare. Katalogdata från Stockholms stadsbibliotek; filmdata från TMDb. This product uses the TMDB API but is not endorsed or certified by TMDB.
  • Källkoden finns på GitHub.

INTEGRITET

  • Inga cookies, ingen analys, ingen spårning, inga konton.
  • Dina val (bibliotek, ”inne nu”, sortering) sparas bara i din egen webbläsare och skickas aldrig någonstans.
  • Typsnitten ligger på sidan själv. Omslag laddas från TMDb och bibliotekets server, som då ser din IP-adress precis som vid all bildladdning på webben. Trailers öppnas på YouTube först när du klickar.
  • Sidan ligger på GitHub Pages, som kan logga IP-adresser av säkerhetsskäl (GitHubs integritetspolicy).
  • Sidan skickar ingen ”referrer”: bildservrar och länkar du klickar på får inte veta att du kom härifrån.
  • Feedbackformuläret sparar bara det du själv skriver.
